# 2048 数字方块

一个无需安装第三方依赖的 2048 小游戏，使用原生 HTML、CSS 和 JavaScript 编写。

## 运行

需要 Node.js 22 或更新版本。在项目目录执行：

```bash
npm start
```

然后打开 <http://localhost:3000>。也可以使用 `PORT=其他端口` 指定端口（PowerShell 中为 `$env:PORT=其他端口`）。

## 玩法

- 使用方向键或 `W`、`A`、`S`、`D` 移动方块；手机上可在棋盘内滑动。
- 每次有效移动后会出现一个新的 `2` 或 `4`。
- 相同数字在移动方向上碰到一起会合并，合并后的数字计入分数。
- 合成 `2048` 即获胜，可以选择继续挑战；棋盘填满且无法合并时游戏结束。
- 点击“撤销”或按 `Z` 撤销上一步；点击“新游戏”重新开始。

游戏进度和最高分保存在浏览器的本地存储中。刷新页面后可以继续当前对局；更换浏览器或清除浏览器数据会清除记录。撤销仅保留最近一步，刷新后不可撤销。
